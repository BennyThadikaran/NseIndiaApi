=========
Utilities
=========

The ``nse._utils`` module contains internal utility functions used by the NSE
library. These functions support common operations such as filesystem path
handling, file downloads, archive extraction, and other internal processing.

The module is **not part of the public NSE API** and is not intended to be
used directly by library users. It is documented here as a reference for
developers and contributors working on the NSE library.
